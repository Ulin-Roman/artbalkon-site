## Режимы сборки и оставшиеся действия

Локальная сборка по умолчанию использует `/api/leads` для тестового Node-сервера. Production workflow задаёт `SITE_MAIL_FORMS=true`, включает PHP и `/api/leads.php`. GitHub Pages задаёт `SITE_STATIC_ONLY=true`: отправка отключена, страницы имеют `noindex`, sitemap не публикуется.

Остаются: итоговая публикация исправления с проверкой `deploy-pages.yml` и результата на обоих хостингах; повторное наблюдение за 11 необойдёнными URL Google; повторная проверка настройки обхода по счётчику после восстановления сервиса Яндекса. Успешная публикация должна быть зафиксирована отдельно после её завершения.
