# Почтовые формы artbalkon.site

REG.RU собирается с SITE_MAIL_FORMS=true: все пять пользовательских форм используют /api/leads.php. Получатель фиксирован: balkonart@yandex.ru. Webhook не используется. Колибри и клиентская аналитика сохраняются. GitHub Pages остаётся статическим предпросмотром без отправки.

PHP 7.3+ и настроенная почтовая служба хостинга необходимы. Отправитель: forms@artbalkon.site. Успешный mail() означает принятие сервером к доставке, но не подтверждает получение во входящих. Проверка рабочего ящика остаётся обязательной при первом реальном обращении; при необходимости настройте SPF/DKIM и SMTP в панели хостинга.

Обработчик проверяет согласие, поля, источник, размер запроса; ограничивает частоту и повторную отправку. В приватной временной папке сохраняет только хеши, идентификаторы и время на 24 часа. Имена, телефоны и ответы в журнал не записываются.

Проверки: php scripts/mail.test.php — подставная отправка без писем; python3 scripts/verify-mail-host.py — проверка опубликованного endpoint без заявки.
